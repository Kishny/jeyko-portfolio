## EcoTrack

- **Pitch** : plateforme de suivi d'impact environnemental pour les entreprises, avec reporting carbone et recommandations.
- **Accroche de la page** : « Mesurer et réduire l'empreinte carbone des entreprises »
- **Stack prévue** : Next.js, Python, PostgreSQL, Chart.js, Docker, Vercel
- **Fonctionnalités** : calculateur carbone, rapports de durabilité, suivi des objectifs, intégrations API
- **Défi** : intégrer des données environnementales hétérogènes provenant de multiples sources.
- **Solution envisagée** : pipeline ETL robuste avec validation de données et calculs scientifiques précis.
- **Tags** : Sustainability, Next.js, Python, Data Analysis, Reporting — catégories `web`, `fullstack`
- **Ancienne page** : `docs/archive/ecotrack.html`

## ArtSpace VR

- **Pitch** : galerie d'art virtuelle en réalité virtuelle permettant aux artistes d'exposer leurs œuvres numériquement.
- **Accroche de la page** : « L'art contemporain sans frontières »
- **Stack prévue** : Unity, C#, WebXR, WebGL, WebSockets, Node.js
- **Fonctionnalités** : navigation VR, exposition 3D, mode multijoueur, profils artistes
- **Défi** : créer une expérience VR accessible depuis le navigateur sans installation complexe.
- **Solution envisagée** : WebXR et optimisation des assets 3D pour le streaming progressif.
- **Tags** : Virtual Reality, Unity, 3D, Art, Immersive — catégories `web`, `uiux`
- **Ancienne page** : `docs/archive/artspace.html`
