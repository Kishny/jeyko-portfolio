[ 01 ] À propos du projet

La beauté mélaninée dans la poche

Ebenora Beauty App prolonge l'e-shop Ebenora sur mobile : une application native pensée pour les femmes aux carnations ébène, brunes et noires, avec catalogue, diagnostic de peau et routines personnalisées.

L'app est développée avec Expo et React Native, s'appuie sur une API Hono typée de bout en bout, et est distribuée en test public via TestFlight.

[ 02 ] Fonctionnalités

Ce que propose le projet

Diagnostic de peau

Quelques questions pour identifier le type de peau et ses besoins.

Routines personnalisées

Des routines ciblées selon la carnation et les problématiques.

Catalogue & panier

Visage, corps, cheveux, maquillage, solaire : tout le catalogue en quelques gestes.

Compte sécurisé

Inscription, connexion et historique des commandes.

[ 03 ] Défi & solution

Résoudre les vrais problèmes

LE DÉFI

Le point de départ

Offrir sur mobile une expérience aussi soignée que le site, avec un parcours diagnostic → routine → achat fluide en quelques gestes.

LA SOLUTION

Ce que j’ai construit

App Expo Router native avec API Hono typée (Drizzle + Turso), authentification Better Auth et builds EAS pour iOS et Android.
